# HelpMate - Lab 2

HelpMate - статический многостраничный прототип платформы, где студенты могут публиковать анкеты и искать работу, а работодатели могут смотреть анкеты и размещать вакансии.

## Что выполнено

- Использованы только HTML и CSS, JavaScript отсутствует.
- Главный референс стиля: [Neumorphism](https://dummy.my/neumorphism) с сайта Dummy.my.
- Выбранная комбинация из Themes: **Neumorphism + Education & Learning**.
- Тема: светлый холодно-серый фон, синий акцент, мягкие внешние и внутренние тени. Для темной системной темы предусмотрена отдельная палитра.
- Все страницы используют единый файл `style.css`.
- Главные фотографии созданы специально для проекта и хранятся локально рядом с HTML-файлами.
- Реализованы адаптивные версии для компьютера, планшета и телефона.
- Добавлены темная системная тема, видимые состояния фокуса и поддержка `prefers-reduced-motion`.
- Все страницы связаны обычными HTML-ссылками.

## Как объяснить CSS на защите

1. `:root` хранит общие переменные цветов, теней, радиусов и ширины контейнера. Переменные названы по-русски: `--фон`, `--текст`, `--акцент`, `--темная-тень`, `--светлая-тень`.
2. `.container` ограничивает ширину контента и центрирует его.
3. `display: grid` используется для колонок, карточек и форм.
4. `display: flex` используется в навигации, кнопках и строках тегов.
5. Neumorphism создается двумя тенями: темной снизу справа и светлой сверху слева.
6. `box-shadow: inset` создает эффект вдавленного элемента для полей и фильтров.
7. `@media` меняет количество колонок и меню на небольших экранах.
8. `:hover`, `:active`, `:focus-visible` показывают реакцию элементов на действия пользователя.
9. Семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer` описывают структуру страницы.

## Простая структура кода

Каждый HTML-файл построен одинаково:

1. `head` содержит название страницы, кодировку, настройку мобильного экрана и подключение `style.css`.
2. `header` содержит логотип и навигацию.
3. `main` содержит уникальный контент конкретной страницы.
4. `section` объединяет крупный смысловой блок.
5. `article` обозначает самостоятельную карточку вакансии, студента или отклика.
6. `aside` содержит дополнительную информацию или действие сбоку.
7. `form` собирает данные из полей `input`, `select` и `textarea`.
8. `footer` завершает страницу и содержит дополнительные ссылки.

Имена CSS-классов оставлены на английском, потому что это распространенный стандарт в веб-разработке. Например, `.button-primary` — главная кнопка, `.job-card` — карточка вакансии, `.profile-header` — верхняя часть профиля. Русские комментарии перед разделами объясняют назначение кода.

## Важно про формы и авторизацию

Это статический прототип без JavaScript, серверной части и базы данных. Формы показывают интерфейс и после отправки переходят на другую HTML-страницу через атрибут `action`. Логины и пароли нигде не сохраняются. Для настоящего проекта потребуется backend и безопасная база данных.

## Короткий ответ для защиты

> Сайт сделан на чистых HTML и CSS. HTML отвечает за структуру и содержание 13 страниц, а один общий файл style.css — за цвета, сетки, кнопки, формы, адаптивность и стиль Neumorphism. Общие значения вынесены в русские CSS-переменные, поэтому дизайн можно изменить в одном месте. JavaScript, сервер и база данных в этой лабораторной работе не используются.
